# Решение дз c1-hw-1

В рамках задания были изучены базовые команды Git, правила оформления коммитов (Conventional Commits) и работа с удалённым репозиторием на GitHub.

## Содержимое папки `solution`:
* [commands.txt](./solution/commands.txt) — шпаргалка с основными командами Git.
* [commits-rules.txt](./solution/commits-rules.txt) — правила оформления коммитов по стандарту Conventional Commits.
